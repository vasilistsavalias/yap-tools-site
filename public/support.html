Support

Something weird? Tell us what happened without sending private data.

Before reporting a bug

  1. Reload the extension from chrome://extensions.
  2. Refresh the affected page.
  3. Try the action once more.

Open an issue

Include the extension name and version, Chrome version, site, expected behavior, and what actually happened.

Never include API keys, private messages, voice notes, transcripts, or screenshots containing personal conversations.

Open a support issue

Security

Do not post security vulnerabilities publicly. Use GitHub's private reporting channel where available and revoke any key you believe was exposed.
