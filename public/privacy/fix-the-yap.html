Fix the Yap!

Privacy policy

Effective 11 November 2026

Data handled

Fix the Yap processes only text that you explicitly select and submit through its context-menu action. It also handles the provider API keys and preferences you enter.

How data is used

  • Provider keys and preferences are stored in Chrome's local extension storage, restricted to trusted extension contexts.
  • Selected text is sent over HTTPS directly to providers you configure.
  • The revised result is returned to the active page or clipboard.
  • The developer operates no backend and cannot access keys, selected text, results, pages, or settings.

The extension has no analytics, advertising, behavioral tracking, profiling, or remote text history. It does not sell data or use it for credit decisions or unrelated purposes.

Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Fix the Yap uses selected text only to perform the user-requested rewrite and does not permit unrelated human access to it.

Retention and deletion

Fix the Yap does not create a text or rewrite history. Use Clear saved keys and settings to remove extension storage, or uninstall the extension to remove its local data.

Provider processing

Browser-held API keys are less secure than keys behind a trusted backend. Use dedicated restricted or spend-limited keys where available. Provider processing is governed by the terms and privacy policy for your API use.

Changes

Material changes to these data practices will be disclosed in the extension and this policy before release.

Fix the Yap is independent and is not affiliated with any supported provider.
